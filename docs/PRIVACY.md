# 拆包智录隐私政策

版本：2026-07-29-2.3

快递单号、录像、标签、备注、Excel 和配对信息默认只保存在商家自己的设备中。录像目录中的 `.unpackvision` 便携索引只保存恢复业务所需的记录字段和相对路径，不保存密码、API 密钥、手机令牌、电脑用户名或绝对业务路径。

手机端会在本机保存由 Android Keystore 保护的工位令牌、应用设置和尚未发送的离线扫码事件。电脑端凭据使用 Windows DPAPI 保存。

Windows 端会在 `%LOCALAPPDATA%\UnpackVision\Logs` 保存本地诊断日志，用于排查崩溃、界面长时间无响应、工位主机启动和配对失败。日志按天及大小滚动，最长保留 14 天，不自动上传；软件不主动写入单号、录像和 Excel 绝对路径、配对令牌、设备密钥或证书指纹，并会对异常文本中的路径和疑似凭据进行二次遮盖。用户可以在“设置 → 关于 → 隐私、安全与支持”打开日志目录并自行删除。

自动更新开启时会访问 GitHub Releases。该请求会向 GitHub 提供互联网通信必需的 IP 地址和常规请求信息。关闭自动更新后仍可手动检查。

手机协同使用证书固定的 HTTPS 连接已配对电脑，视频流使用 RTSPS 和独立设备令牌。软件默认不提供公网入口。

相机权限仅在进入配对、扫码或摄像功能时申请；通知权限只用于版本更新提醒；安装 APK 由安卓系统单独授权。麦克风录音默认关闭，当前版本不申请麦克风权限。

“帮助作者统计匿名日活”是独立可选项。启用后，应用生成随机本机密钥，并按北京时间日期和平台计算不可跨日关联的 HMAC 匿名值。每天最多向固定 Cloudflare HTTPS 地址发送一次日期、匿名值、平台、应用版本和发布渠道；不会发送硬件序列号、IMEI、MAC、账号、单号、录像、备注、Excel 或路径。

原始匿名日记录计划保留 35 天，每日聚合数字保留 24 个月。用户可在设置中随时关闭；关闭后立即停止请求并删除本机统计密钥，重新开启会产生新的随机身份。拒绝或撤回不影响录像、扫码、Excel、手机协同和更新。

统计仅使用出站 HTTPS，不开放互联网入站端口、不接收远程指令、脚本或配置。网络故障、限流或服务不可用不会阻塞软件启动或本地功能。

赞助页面展示作者提供的微信和支付宝二维码，不接入支付 SDK，不读取付款人、金额、订单、账号或付款结果。

面单和录像可能包含个人信息，商家应自行设置访问权限、保存期限和合法使用范围。
