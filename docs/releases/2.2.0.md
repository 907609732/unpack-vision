# 电商拆包智能录像 2.2.0

这是隐私合规与安全迁移版本。

- 全新钛金属电光蓝品牌图标，Windows 与安卓统一品牌。
- 首次启动先展示用户协议和隐私政策；默认不启用任何使用统计。
- Windows 与安卓增加更新提醒、关键安全更新标记和发行说明入口。
- 设置页增加“支持作者”；未配置真实支付宝、微信二维码时不会显示测试码。
- 手机控制升级为证书固定 HTTPS，媒体发布升级为 RTSPS。
- 旧手机配对会失效，需要在电脑端重新生成二维码配对一次，历史记录不会删除。
- 增加速率限制、请求大小和字段长度限制、Host 与录像路径验证、配对失败锁定。
- GitHub 增加 CodeQL、Gitleaks、OSV、Trivy、actionlint 与 Dependabot。

Windows 安装器尚未取得代码签名，本版本按 Prerelease 发布。业务数据、录像、Excel 和本机设置不会被安装包覆盖。
