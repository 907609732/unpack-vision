# 拆包智录 2.5.2 预发布说明

2.5.2 是 2.5.1 的本地可靠性补丁，重点修复录像目录迁移后源副本未释放，以及扫码枪输入被拼接后误启动下一段录像的问题。

## 修复

- 录像目录迁移采用复制、SHA-256 校验、设置与数据库路径提交、再次校验、清理源副本的分阶段流程。
- 数据库中的主录像、截图、多机位资产、媒体分段和恢复路径只对已验证文件进行事务式改写。
- 目标缺失、内容变化、文件占用、未完成录像和外部文件一律保留在源目录，并生成可重试清单。
- Raw Input 扫码字符使用独立短帧边界，不再沿用业务防误扫时长缓存未结束字符。
- Raw Input 与焦点输入框回退通道增加双向去重，阻止同一物理扫码重复触发。
- 协调器按扫码到达时间拦截并发镜像命令，同时保留间隔后重扫当前单号结束录像的业务行为。
- 旧版已经完成“只复制”迁移的工作区可在新版中识别并安全修复，执行前仍需用户确认。

## 数据兼容

- 内部包 ID 仍为 `EcommerceUnpackRecorder`，数据库、设置、录像命名、Excel 格式和 API 路径保持兼容。
- 修复过程不会删除未验证文件，也不会移动用户选择的 Excel 或外部 HIK 录像。
- Android `applicationId` 继续为 `com.unpackvision.mobile`，版本号为 `2.5.2`，`versionCode` 为 `20502`。

## 发布状态

Windows 安装器未取得可信 Authenticode 代码签名，因此 2.5.2 只能作为本地测试包或 GitHub Prerelease，不能标记为正式稳定版。
