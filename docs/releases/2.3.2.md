# 拆包智录 2.3.2

## 改进

- 使用新的苹果风格包裹与摄像头图标，统一桌面端、安装器和安卓启动器品牌。
- 将用户可见的软件名称统一为“拆包智录”，保留内部兼容标识以支持原位升级。
- Windows、StationHost、兼容同步服务和安卓协同端统一升级到 2.3.2。

## 兼容性

- 不修改 SQLite、Excel、配置 JSON、录像命名、REST 路径、安卓 applicationId 或手机配对协议。
- 使用相同 Velopack 包 ID 和安卓签名证书覆盖升级，不清除现有业务数据。
- Windows 安装器尚未使用可信代码签名，本版本仅作为本地预发布构建提供。
