# 电商拆包智能录像 2.1.0

这是统一品牌并加入正式安装、自动更新和安卓协同发布能力的首个公开版本。

## 主要变化

- Windows 端采用 Velopack 每用户安装器，后续可从 GitHub Releases 获取完整包和差分更新。
- 软件正式更名为“电商拆包智能录像”，内部数据目录和 API 兼容名继续使用 `UnpackVision`。
- Windows 设置页增加自动更新、立即检查、更新进度、开源仓库、Windows 下载和手机 APK 下载二维码。
- 安卓设置页增加每日更新检查、系统下载、SHA256 校验和系统安装授权流程。
- Excel 新记录统一标记 `【电商拆包智能录像】`，重新同步时兼容迁移旧 `【拆包智录】` 标记。
- 撤销配对设备会永久删除设备详情并断开活动媒体会话，不删除历史录像和单号。
- 电脑端单号、时间、路径、状态、标签、备注和说明文本支持鼠标选择、右键复制及 `Ctrl+C`。
- 使用全新“包裹＋红色录像点”图标，统一 Windows、Android 和项目文档品牌。

## 首次安装说明

- 从旧便携版迁移时直接运行 `电商拆包智能录像-Setup.exe`。
- 现有 `%LOCALAPPDATA%\UnpackVision`、`%USERPROFILE%\Videos\UnpackVision`、Excel 和录像目录不会被覆盖。
- 当前 Windows 安装器尚未取得代码签名证书，首次下载可能出现 SmartScreen 提示；可通过 `SHA256SUMS.txt` 和 GitHub 构建来源证明核验文件。
- 当前测试机若安装的是 Debug APK，需要先卸载 Debug 版，再安装正式 APK，并重新配对电脑。以后保持相同签名即可覆盖升级。
