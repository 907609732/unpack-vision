# 拆包智录 2.4.18 预发布说明

2.4.18 简化相机设置流程：设置主页不再直接展示冗长的当前机位表单，双击机位或点击“配置选中机位”后，在独立弹窗中选择本地摄像头、IPC 或海康录像机并填写对应参数。

- 单机位和多机位模式均保留机位列表，方便查看并配置已保存来源。
- 添加新机位与编辑现有机位复用同一弹窗，取消时不会修改原配置。
- 弹窗根据来源类型只显示相关入口，高级录像和画面参数默认收起。
- 海康录像机通道发现移入弹窗，仍支持保存时补充可用通道并遵守4机位上限。
- 配置变化后会使旧性能测试结果失效，保存前继续使用原有测试流程。

Windows 安装包仍未取得可信代码签名，本版本仅作为预发布测试版。
