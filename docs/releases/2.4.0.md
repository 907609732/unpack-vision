# 拆包智录 2.4.0

2.4.0 是四机位同步预览与录像预发布版。

- 单个工位最多启用4个USB、虚拟、手机、IPC或海康录像机通道。
- 主页按1路全屏、2路左右、3至4路2×2显示，点击画面可放大。
- 每单保存各机位独立原片和一份1080p/15fps合成视频。
- 主机位中断超过5秒会使整单失败；副机位中断写入占位画面、自动重连并记录媒体缺口。
- 历史记录默认播放合成视频，可在保持时间位置的情况下切换机位。
- SQLite、便携索引和API新增媒体资产与缺口，同时保留旧版主视频字段和接口。
- 多机位方案保存前必须通过15秒真实性能检测。
- 设置页新增安全卸载入口；默认保留数据库、设置、配对信息、录像和Excel。
- 用户选择永久清理时连续进行两次警告，只删除经过工作区ID验证的软件数据；Excel和录像目录中的其他文件不会删除。
- 直接从Windows“已安装的应用”卸载时没有清理授权，因此始终保留业务数据。

Windows安装包在可信代码签名验收完成前仍只能作为 Prerelease 发布。
