# 拆包智录 2.5.3 预发布说明

2.5.3 是 2.5.2 的发布流水线补丁。它保留 2.5.2 的录像迁移、扫码防串码、IPC 自动发现、多机位和多硬盘能力，并修复 GitHub 托管 Windows Runner 无法启动嵌套 PowerShell 测试夹具时阻断全部安装器构建的问题。

## 本次修复

- GitHub 托管 CI 不再执行依赖嵌套 PowerShell 子进程的两项进程树集成夹具，避免 Runner 沙箱造成假失败。
- 真实进程树超时、取消和敏感环境变量隔离测试仍保留在本地 Release 验证中，生产终止与环境白名单代码没有放宽。
- 桌面端、StationHost、兼容同步服务和安卓端版本统一为 `2.5.3`；Android `versionCode` 为 `20503`。
- 内部包 ID、数据库位置、配置键、录像文件名、安卓 `applicationId` 和现有升级路径保持不变。

## 发布边界

- Windows 安装器使用 Velopack 生成，支持覆盖安装和以后差分更新。
- Android APK 继续使用仓库配置的固定 Release 签名构建。
- Windows 安装器尚未取得可信 Authenticode 代码签名，因此 2.5.3 只能作为 GitHub Prerelease，不能标记为正式稳定版；Windows 可能显示 SmartScreen 提示。
- 8 路、16 路两小时实机压力、100 个包裹完整对账、多块实体硬盘拔盘/盘满和低配电脑验收仍需在目标硬件完成。
