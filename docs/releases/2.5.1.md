# 拆包智录 2.5.1 预发布说明

2.5.1 是 2.5.0 工程预览版的本地补丁版本，用于可靠区分并覆盖安装当前修复构建。

## 本次更新

- IPC 配置页新增局域网自动扫描，支持标准 ONVIF、兼容探测和海康 SADP。
- 扫描结果显示来源、进度和兼容提示；发现设备后仍需填写凭据并通过实时预览验证。
- 扫描候选不会自动复用旧设备账号密码，也不会在未确认时主动向候选地址发送凭据。
- 修复快速切换摄像头或预览后立即关闭配置窗口时的生命周期竞态和崩溃。
- 海康 SADP 辅助程序采用固定版本和 SHA256，并仅打包经过审计的可执行文件与许可证。
- 加固外部工具超时、取消、进程树清理、最小环境变量和流式 XML 隐私边界。

## 兼容性

- Windows 内部包 ID 继续为 `EcommerceUnpackRecorder`。
- 用户数据继续保存在 `%LOCALAPPDATA%\UnpackVision`。
- 数据库、录像目录、Excel 路径、手机配对信息和现有 `/api/v1` 接口不主动重置。
- Android `applicationId` 继续为 `com.unpackvision.mobile`，版本号为 `2.5.1`，`versionCode` 为 `20501`。

## 尚未完成的稳定版门禁

- 8 路和 16 路各连续运行 2 小时的实体机验收。
- 100 个包裹与 SQLite、录像、Excel 的完整对账。
- USB、IPC、NVR、手机混合来源以及多块实体硬盘拔盘、换盘、盘满和低配电脑测试。
- Windows 安装器尚未取得可信 Authenticode 代码签名。

因此 2.5.1 只能作为本地测试包或 GitHub Prerelease，不能标记为正式稳定版。
