# 拆包智录 2.4.10 预发布说明

2.4.10 是 Windows 桌面端相机配置体验与海康录像机接入改进版。

## 本次改进

- 相机设置整理为“选择录像模式、配置当前机位、测试并保存”三步流程。
- 单机位隐藏多机位专属操作，多机位排序、删除和设主机位统一收进“更多操作”。
- 根据本地摄像头、IPC 或海康录像机来源，仅显示相关配置入口。
- 录像规格和画面调节默认折叠，降低首次配置复杂度。
- 海康录像机支持发现并添加实际可用通道，可选择优先使用子码流。

## 兼容性

- 保留现有数据库、录像目录、Excel 绑定和相机配置。
- 内部安装包 ID 与数据目录保持不变，可直接从 2.4.9 覆盖升级。
- Windows 安装器未取得可信代码签名前仍属于本机预发布测试版本。
