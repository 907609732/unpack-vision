# 拆包智录 2.5.0 预发布说明

2.5.0 是 8/16 路录像与多硬盘存储池的工程预览版。它用于验证新媒体和
存储边界，不是已完成生产验收的稳定版。

## 已进入源码的能力

- 机位配置上限从 4 路扩展到 16 路，主页提供 1、2、3、4、8、16 画面布局；
  预览分配仍然只是视图状态，不会抢占或重建录像机位。
- 每个机位拥有独立录像写入循环，合成画面使用单独写入循环和统一结束屏障；
  副机位阻塞不再串行拖慢其他机位。
- 1 至 4 路默认生成合成片，5 路以上默认关闭合成片；用户显式配置仍可覆盖
  默认值，主机位原片始终是旧接口的兼容路径。
- 新增 4 路高清、8 路均衡、16 路节能容量模型，以及编码帧率、队列、延迟和
  硬件编码器等运行指标契约。
- 5 至 16 路方案必须通过当前机位、合成设置和全部启用录像盘位的 60 秒真实性能
  测试；测试结果带配置指纹，修改任一来源、画质、合成选项或盘位后会自动失效。
- 主机位写入器失败或连续 5 秒没有画面时，桌面端会自动结束当前业务记录并保留
  可恢复临时文件；副机位或合成片收尾失败不会再连带丢失已经完成的主机位录像。
- 副机位缺失、编码失败和文件定稿失败都会形成媒体缺口或 `Partial` 资产，不能再
  被误报为完整录像；实时状态返回实际编码 FPS、处理延迟、编码器和硬件加速状态。
- 新增不限数量的录像存储目标、卷标识、优先级、健康检查和整单分配。旧的
  单一录像目录自动成为第一个盘位，不迁移或改写已有录像。
- 开始一单前按预计码率和最长录像时长预留空间；安全线取 10 GiB 与“预计
  完成一单空间 + 5 GiB”的较大值。低于 15% 或预计不足 2 小时会警告，低于
  安全线的盘位不会接收新单。
- 媒体资产和分段记录保存盘位 ID、相对路径、编码器、水印与恢复信息；旧
  `VideoPath`、Excel、API 和便携索引仍以主机位为兼容投影。
- 新增 GStreamer 1.28.5 运行时、必需元素与 H.264 编码器功能探测。编码器选择
  顺序为 QSV、NVENC、AMF、Media Foundation 和许可白名单内的软件回退。
- 新增 FFmpeg 8.1.2 版本及许可证探测；含 GPL 或 nonfree 组件的本机二进制
  不得复制进发布包。
- IPC 扫描增加有界 ONVIF 兼容探测和可选的海康 SADP 辅助。发布包固定并校验
  完整上游 CLI，但本软件只调用不携密码的只读发现子命令，并随包附带 Go
  标准库及实际编译进二进制的依赖许可证和 NOTICE。
- 历史播放器提供统一时钟的最多 4 路同步播放基础，包括播放、暂停、拖动、
  倍速、起始偏移和离线占位；8/16 路回放仍需性能准入后再开放。

## 仍需完成的发布验收

- GStreamer 探测代码不代表当前电脑已经安装或启用了 GStreamer，也不代表主
  录像链路已经在所有来源上切换完成。
- 尚未记录 8 路和 16 路各连续 2 小时、混合 USB/IPC/NVR/手机来源、100 个包裹
  对账、断流恢复和多盘切换的实体机结果。
- 每台目标电脑仍须实际执行 60 秒全链路性能准入；低配电脑基线、分片 MP4 崩溃
  恢复和 LGPL 发布包审计必须通过后，才可以把相应能力标记为生产可用。
- Windows 安装器仍未取得可信 Authenticode 代码签名，只能作为 GitHub
  Prerelease 或本地测试包提供，不能标记为稳定版。

## 兼容性

- 产品名称继续为“拆包智录”。
- 内部 Windows 包 ID 继续为 `EcommerceUnpackRecorder`。
- 安卓 `applicationId` 继续为 `com.unpackvision.mobile`，2.5.0 的
  `versionCode` 为 `20500`。
- `%LOCALAPPDATA%\UnpackVision`、SQLite、录像命名、Excel 六列结构、手机配对
  和现有 `/api/v1` 接口不主动改名或清空。
