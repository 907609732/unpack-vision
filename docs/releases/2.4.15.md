# 拆包智录 2.4.15 预发布说明

2.4.15 扩展了主页多画面右键摄像头选择器。

- 右键任一预览画面时，按“当前机位、其他已配置来源、Windows 本地摄像头”分组显示来源。
- 自动枚举当前 Windows 可调用的 USB 摄像头、iVCam 等虚拟摄像头。
- 可直接启用已保存但未加入当前方案的 IPC、RTSP 和海康录像机通道。
- 四机位已满时，额外来源替换当前右键画面对应机位，不超过四路采集上限。
- 录像期间仍允许切换当前已启用机位的预览位置，但禁止启用或更换采集来源。
- 新来源启动失败时恢复原机位方案，避免保存损坏的配置。

本版本仍为未签名 Windows 预发布版，仅用于测试验证。
