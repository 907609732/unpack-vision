# 拆包智录 2.4.2

2.4.2 是 Windows 桌面端录像目录迁移预发布版。

- 修改录像保存位置时，自动检测旧目录中的完成录像和 `.unpackvision` 便携索引，并询问是否迁移。
- 选择迁移后先复制到新盘、逐个 SHA-256 校验并生成本地迁移报告；旧目录始终保留，不自动删除。
- 迁移中断、空间不足、权限不足或发现同名不同内容文件时，设置不会切换，旧录像保持原样。
- 正在录制的 `.partial.mp4` 临时文件不会被当作完成录像迁移。

本版本不修改 Excel、SQLite、摄像头与手机配对信息。Windows 安装包在取得可信代码签名前仍仅作为 Prerelease 提供。
