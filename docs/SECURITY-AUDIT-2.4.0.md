# 2.4.0 预发布验证记录

- Windows Release 构建：0 警告、0 错误。
- .NET 自动化测试：115 项全部通过，无跳过。
- Android Debug 单元测试与 APK 构建通过。

## 安全边界

- `ScanRecord.VideoPath` 继续只指向主机位，新增媒体接口只按资产 ID 返回内容并验证录像根目录。
- 局域网设备仍使用现有 HTTPS/WSS/RTSPS、设备权限和撤销机制；本版本未新增公网入站端口。
- 多机位配置不写入便携索引中的摄像头密码、设备令牌或绝对业务路径。
